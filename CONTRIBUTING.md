# Contributing to rads

This package is developed and maintained by PHSKC-APDE according to our internal R package development standards:

**[PHSKC-APDE package-toolkit standards](https://github.com/PHSKC-APDE/package-toolkit/standards)**

If you are planning to contribute — whether a bug fix, a new feature, or a documentation change — please read those standards first. This helps make sure your contribution lines up with our conventions.

Reach out to the maintainers or developers (see the `DESCRIPTION` file, or open a [GitHub issue](https://github.com/PHSKC-APDE/rads/issues)) if you do not have access to the standards repository.
